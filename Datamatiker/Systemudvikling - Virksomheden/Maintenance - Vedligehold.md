# Opgave kategorier:
Groft set er opgaverne i vedligehold og udviklingen ret ens. Begge dele kræver planlægning, design, analyse og så videre. 
I vedligehold er der dog tendens til at man bruger mere tid på bug fixes og forbedringer end på at skrive helt ny kode.
Det er ikke ualmindeligt at 75% af et projekts omkostninger bliver brugt på vedligehold.

## Perfektive opgaver: 50%
*Perfektivt aspekt: Viser en handling som afsluttet eller fuldført.*
- Videreudvikling på eksisterende funktioner og tilføjelse af nye.
## Adaptive opgaver: 25%
- Ændrer applikationen så den passer til brugernes behov og miljø.
## Corrective opgaver: 20%
- Bug fixes og andre lapninger og reperationer. 
## Preventive opgaver: 5%
- Refaktorering af koden for at forebygge eller lære mere omkring koden for nemmere at kunne vedligeholde i fremtiden.
	- Clarification
	- Code resuse
	- Improved Flexibilty
	- Bug swarms
	- Bad programming practices
