I almindelig React til web vil HTML blive renderet i browserens DOM, men i React Native vil HTML blive renderet som det native element der skal bruges. 
Et <view> bliver på iOS til et UiView og Android får et android.view. View kan sammenlignes med en <div> i HTML, altså en container til andre elementer
Dette gør også at man får den native komponenter som man er vant til fra hvert OS. Kalender hjul på iOS f.eks
