I en problem der hedder at man vil forudsige prisen på et hus kunne man vælge at kigge på følgende:

| Lokation | Antal kvm | Opførsels år | Pris  |
| -------- | --------- | ------------ | ----- |
| Feature  | Feature   | Feature      | Label |

Lokation, antal kvm og opførsels år er de features der vil hjælpe os med at bestemme vores label/pris.

### Feature Engeneering:
Processen i at klargøre sine features eller data for at kunne bruge det i den algoritme man ønsker at arbejde med.
