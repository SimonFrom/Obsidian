#### <u>Overfitting:</u>
Hvis man ikke har saneret sin input data til træning ordentligt og den indeholder støj, outliers eller spøjs data, vil man ende med en Overfitted model. 
Denne model vil klare sig godt på trænings data, men skidt på validerings data.

Typiske fejl kan være:
- Modellen er for kompleks
- For mange features
- For lidt data
- Meget høj varians i data


#### <u>Underfitting:</u>
Dette er når en model ikke lærer de rigtige tendenser og mønstre fra trænings dataen. Den vil være dårlig på både trænings og validerings data.

Typiske fejl kan være:
- For simpel model
- For ensformig data
- For lidt features
- Ikke nok trænings data
- Højt vægtet data
