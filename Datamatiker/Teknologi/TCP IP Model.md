I praksis bruges TCP/IP modellen fremfor OSI. 


1. Network Interface (OSI lag 1-2)
    1. Svarer til Physical og Data link layer i OSI. Her hører alt hardware til. Kabler, switches, netværks kort osv.
2. Internet (OSI lag 3)
    1. IP adresser og routere hører til her.
3. Transport (OSI lag 4)
    1. Bryder data ned og samler det igen og hvad det kræver at sende data, TCP eller UDP f.eks.
4. Application (OSI lag 5-7)
    1. Svarer til Application, Session og Presentation layer i OSI.
