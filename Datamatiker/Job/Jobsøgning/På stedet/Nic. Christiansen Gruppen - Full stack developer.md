# Full stack developer, Nic. Christiansen Gruppen

## Opslaget
Udvikling og vedligehold af .NET/C#-software i både frontend og backend: API'er, integrationer og forretningslogik, SQL Server og Azure-databaser, test og fejlsøgning, sprints, deployment og automatisering. Familieejet bilkoncern i Kolding (import, detailhandel, finansiering og leasing) med over 2.300 ansatte. Arbejdsplads: Trianglen 20, Kolding. Ansøgninger vurderes løbende, "send hurtigst muligt".

Opslaget nævner udtrykkeligt nyuddannede datamatikere og siger "Du behøver ikke have mange års erfaring" og "Du behøver ikke sætte flueben ved det hele".

Kontakt: Anders Duelund, Head of Digital Solutions & Integration, +45 27 90 23 33.

Fuldt opslag: https://app.jobmatchprofile.com/mdre3y

De beder om, at man skriver, hvad man har arbejdet med, og hvad man gerne vil lære mere om.

## Hvor jeg passer
- **.NET, C# og objektorienteret programmering:** FuelPace (ASP.NET Core Web API, EF Core, Clean Architecture). Eksporten har hvert filformat som sin egen klasse bag et fælles interface.
- **REST-API'er:** API-ruter i Elysia hos AirPlate og ASP.NET Core Web API i FuelPace.
- **HTML, CSS, JavaScript og React:** frontend hos AirPlate i React, TypeScript, Tailwind og TanStack Query.
- **Git og versionsstyring:** Git og GitHub i alle projekter.
- **Nyuddannet datamatiker:** færdig i januar 2027.

## Hvor jeg mangler noget
- **SQL Server:** har MySQL og PostgreSQL, men ikke SQL Server.
- **Azure:** ingen erfaring (opslaget skriver "gerne Azure").
- Der er ikke noget krav om antal års erfaring.
