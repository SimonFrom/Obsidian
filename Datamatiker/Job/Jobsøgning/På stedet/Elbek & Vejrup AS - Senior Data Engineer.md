# Senior Data Engineer, Elbek & Vejrup A/S

## Opslaget
Stillingen er i teamet Data & AI, der bygger dataplatforme til danske virksomheder som fundament for agentisk AI. Arbejdet er ELT fra ny kilde til gold-laget, mest til Power BI. Platformen er bygget på Azure med open source-værktøjer, primært Python. Man kan arbejde fra Ballerup, Aalborg, Aarhus eller Kolding. Om hjemmearbejde står der "Hjemmearbejde aftaler du med din personaleleder". Fristen er "Snarest muligt", med løbende samtaler.

Kontakt: Rasmus Åkesson, Business Line Manager for Data & AI, 28994648, raa@elbek-vejrup.dk.

Ansøgning: CV og 10-12 linjer om dig selv til job@elbek-vejrup.dk.

Fuldt opslag: https://www.jobindex.dk/jobannonce/h1719803/senior-data-engineer-byg-dataplatforme-der-baerer-fremtidens-ai

## Hvor jeg passer
- **Python:** ROEQ og dataanalyseprojektet på studiet.
- **Interesse for AI-agenter:** MCP-server og Claude Code.
- **Data fra forskellige kilder:** InfluxDB og MySQL hos AirPlate.

## Hvor jeg mangler noget
- Opslaget kræver "har flere års erfaring som data engineer".
- Azure eller tilsvarende cloud (krav).
- ELT og medallion-lag (bronze/silver/gold).
- Stillingen er mere dataplatform end softwareudvikling.
