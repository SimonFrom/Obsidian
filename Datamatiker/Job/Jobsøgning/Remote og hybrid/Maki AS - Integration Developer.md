# Integration Developer, Maki A/S

## Opslaget
Maki er en nordisk legetøjsdistributør (B2B, over 100 brands, sælges i mere end 6.000 butikker og webshops). Stillingen er i afdelingen DIGIT (Digital Transformation & IT) sammen med et nyt AI-team. Opgaverne:
- integrationer og automatiseringer på en Azure-iPaaS (Functions, Logic Apps, API Management), og automatisering med n8n, hvor det passer
- API'er
- AI-værktøjer i udviklingen
- sikkerhed, logning og overvågning
- dokumentation
- at hente udviklingsopgaver hjem fra eksterne leverandører

Systemerne er ERP, PIM og lager. Arbejdsstedet er Nydamsvej 21, 8362 Hørning, og "Hjemmearbejde: Muligt". Fristen er "Snarest muligt".

Kontakt: Brian Kofoed, DIGIT Director, +45 29 99 28 53.

Ansøgning: CV og ansøgning på mail til jobs@maki.dk med emnet "Integration Developer".

Fuldt opslag: https://www.jobindex.dk/jobannonce/h1710579/integration-developer-til-maki-a-s-nordens-foerende-legetoejsdistributoer

## Hvor jeg passer
- **Integrationer, API'er og automatiseringer:** API-ruter og genberegning på tværs af InfluxDB og MySQL hos AirPlate, ASP.NET Core Web API i FuelPace og automatiserede tests hos ROEQ.
- **C#, Python eller JavaScript/TypeScript:** alle tre.
- **Versionsstyring, test og deployment:** Git og GitHub, automatiserede tests i Python.
- **Dansk og engelsk:** ja.
- **MCP (nævnt som relevant):** MCP-serveren CykelService.Mcp i C#.
- **ERP-integrationer (relevant):** han har brugt Odoo dagligt hos ROEQ, men kun som bruger.

## Hvor jeg mangler noget
- Azure, Functions, Logic Apps, API Management og Azure DevOps. Der står "gerne", men Azure eller lignende cloud er et krav.
- iPaaS og n8n.
- Der står ikke noget om antal års erfaring.
- Afstand: Hørning er ca. 1 t 15 min fra Vissenbjerg, men der er mulighed for hjemmearbejde.
