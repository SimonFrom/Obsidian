# Fullstack-udvikler, IDA

## Opslaget
Webudvikling fra idé til implementering i teamet "Hverve og Synlighed" sammen med product owner, UX/UI-designere og andre udviklere. IDA er fagforening for ingeniører og IT-folk med over 185.000 medlemmer. Stak: C# .NET 10, Umbraco (headless CMS), NServiceBus, MSSQL, MongoDB, Next.js med TypeScript, Cypress, Chromatic, GitHub, Docker og Figma. Rekrutteringen går gennem European Search Company. Frist "hurtigst muligt", og de indkalder løbende til samtaler.

Arbejdsform: "Vi møder ind sammen minimum to dage om ugen". Kontoret ligger på Kalvebod Brygge 31-33, København V.

Kontakt: Christoffer Bjørk Petersen (+45 2080 1638) eller Brian Ranvits (+45 2048 0548), bra@europeansearch.dk.

Fuldt opslag: https://europeansearchcompany.com/job/fullstack-udvikler-til-ida-2/. Ansøg via Emply: https://europeansearchcompany.career.emply.com/apply/fullstack-udvikler-til-ida/j2a0de/da

## Hvor jeg passer
Opslaget har ingen egentlig kravliste. Sammenlignet med stakken:
- **C# og .NET i backend:** FuelPace (ASP.NET Core Web API, EF Core, PostgreSQL, Clean Architecture).
- **TypeScript i frontend:** React, TypeScript, Tailwind og TanStack Query hos AirPlate.
- **Git(Hub) og Docker:** står i CV'et.
- **Samarbejde med forretningen:** FuelPace erstatter en træners Excel-ark. Kundekontakt fra mange år som cykelmekaniker.

## Hvor jeg mangler noget
- Next.js (har React), Umbraco, NServiceBus, MongoDB, MSSQL og Cypress.
- Opslaget skriver: "Vi leder ikke efter et bestemt antal års erfaring".
- Afstand: kontoret ligger i København, og man skal møde ind mindst to dage om ugen.
