# Senior .NET Developer, GLS Denmark A/S

## Opslaget
Jobbet er at designe, udvikle og videreudvikle C#/.NET-løsninger, cloud-first i Azure, til GLS' pakkeflow. Man er med i arkitektur og tekniske beslutninger, holder kvaliteten med automatiske tests og code reviews og følger løsningerne til stabil drift. IT-afdelingen har over 80 ansatte. Stak: C#/.NET, GitHub Actions, Grafana, Docker og Kubernetes, RabbitMQ og Kafka, SQL og MongoDB, og agentisk AI. Arbejdsstedet er Kokmose 3 i Kolding, med "mulighed for hjemmearbejdsdage".

Kontakt: Morten Jepsen, Software Development Manager, Morten.Jepsen@gls-denmark.com.

Ansøgning: CV og svar på spørgsmål senest 3. december 2026.

Fuldt opslag: https://www.jobindex.dk/jobannonce/h1713941/senior-net-developer-kolding

## Hvor jeg passer
- **Relevant IT-uddannelse:** datamatiker (januar 2027).
- **Agil udvikling:** fra studiet og gruppeprojekter.
- **Softwarearkitektur:** Clean Architecture i FuelPace.
- **Ansvar og kommunikation:** mange års kundekontakt som cykelmekaniker.
