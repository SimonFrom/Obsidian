# Senior Full-Stack Developer - Web & Commerce Applications, DLG

## Opslaget
Jobbet er teknisk ejerskab af kundeportaler, B2B/B2C-handel og interne værktøjer fra design til produktion. Frontend er React, Next.js og TypeScript, og backend er C#/.NET og/eller Python/Django. Der er integrationer til Storyblok, Commercetools, Struct, Canto og Azure, og levering sker via CI/CD i Azure DevOps. Stillingen kan placeres i Fredericia eller Flensburg. Arbejdsformen: "Mobile work is possible in accordance with company policies, combined with regular onsite collaboration". Fristen er 20. december 2026, og de behandler ansøgninger løbende. Opslaget er på engelsk.

Der står ingen kontaktperson.

Fuldt opslag: https://jobs.dlg.dk/job-invite/438/?locale=en%5fGB
